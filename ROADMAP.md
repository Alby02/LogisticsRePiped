# LogisticsRePiped - Roadmap

This roadmap mirrors the core progression and feature set of the original Logistics Pipes mod, adapted for modern Minecraft.

## Phase 1: The Basics (Core Routing)
- [ ] **Base Pipe Framework:** Visual connection of pipes, basic item transport.
- [ ] **Extraction Pipe:** Pulls items from attached inventories.
- [ ] **Insertion Pipe (Basic Pipe):** Accepts items and inserts them into attached inventories.
- [ ] **Unrouted Pipe:** A simple connective pipe that just passes items along.
- [ ] **Wrench item:** For configuring connections and pipe settings.

## Phase 2: Logistics & Sorting
- [ ] **Provider Pipe:** Makes items in attached inventory available to the logistics network.
- [ ] **Request Pipe:** GUI to request specific items from the network.
- [ ] **Supplier Pipe:** Actively keeps an attached inventory stocked with specified items.
- [ ] **Chassis Pipes (Mk1 - Mk5):** Modular pipes that accept upgrade/behavior modules.
- [ ] **Basic Modules:** Extractor module, ItemSink module, Polymorphic ItemSink module.

## Phase 3: Auto-Crafting
- [ ] **Crafting Pipe:** Attaches to a crafting block (like a crafter or an auto-crafting table) to request ingredients and output results.
- [ ] **Satellite Pipe:** Routes specific items to specific sides of a machine for complex recipes.
- [ ] **Crafting Modules:** For chassis support.

## Phase 4: Network Management & Advanced Features
- [ ] **Power System Integration:** Energy costs for requests and extractions (optional but classic feature).
- [ ] **Remote Orderer:** Handheld item to request items remotely from the network.
- [ ] **Fluid Logistics:** Extractor, Provider, and Request pipes for fluids/liquids.
- [ ] **Logistics Security Station:** Network permission management.
- [ ] **Logistics HUD:** Augmented reality glasses or modules to see items traveling and network stats.

## Future / Modern Iterations
- [ ] Integration with modern storage mods (e.g., Tom's Simple Storage, AE2, RS) as external storage interfaces.
- [ ] Performance optimizations for large networks (batching item updates).
