# LogisticsRePiped

LogisticsRePiped is a spiritual successor to the classic Minecraft mod **LogisticsPipes**. Our goal is to bring back the intricate, satisfying, and item-routing goodness of the original mod to modern Minecraft versions using the Architectury API (Fabric & Forge).

## About the Mod

Seeing your items physically travel through tubes is a distinct joy that modern storage mods often abstract away. Sometimes it just feels good seeing the items moving to the right place.

## Features

- **Item Routing:** Intelligent item transport with specialized pipes.
- **Auto-Crafting:** On-demand crafting systems with crafting pipes and satellites.
- **Sorting & Supplying:** Advanced sorting rules and supplier networks.
- **Cross-Platform:** Built with Architectury to support both **Fabric** and **Forge**.

## Getting Started / Installation

**Downloads:**
The mod will be available to download on both **Modrinth** and **CurseForge**.

**Dependencies:**
- [Architectury API](https://modrinth.com/mod/architectury-api)
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) (for Fabric)
- [Kotlin for Forge](https://curseforge.com/minecraft/mc-mods/kotlin-for-forge) (for Forge)
